# Storyman Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Rebuild the blue torch-and-trident figure as a slopmax stickman (one skeleton, three props, one still scene), without the speech bubble.

**Architecture:** Paint flat source bitmaps, one bone each, and trace them with `tools/bonepaper_gen/out/bluehairsvg/build.py` (`regions` + `brush_svg`). Do not trace the photograph. Rasterize the full padded canvas at 4× with `rsvg-convert`, pack `@:` items, and pose them in one scene. `hand.py` stays untouched.

**Tech Stack:** `tools/bonepaper_gen/.venv/bin/python` (Pillow is in that venv), `brush_svg`, `svg_export.Scene`, `rsvg-convert`, motionlib `scene_xml` for the `.ats`.

## Global Constraints

- Do not edit `hand.py`. Do not reimplement the brush.
- `JITTER = 0.5`, brush 14, `PAD = 40`, `SAMPLE = 4`. Those live on the tracer. Read them from `bluehairsvg/build.py`. Do not copy new numbers.
- Do not crop a bone to its alpha box. `bluehairsvg.raster` crops. Do not call it. Keep the full padded canvas, as `out/sun/build.py` `raster` does.
- Joint in the source bitmap `(jx, jy)` → offset `-((jx + 40) * 4)`, `-((jy + 40) * 4)`. Write with a normal f-string, `f'x_offset="{xo:.4f}" y_offset="{yo:.4f}"'`.
- Multiply every `<point x y>` by 4. `meta.txt` `scale` is `0.25`. Scene `<unit scale>` for every redrawn item is `0.25`. A missing scale counts as 1, so leaving it paints the figure four times too big.
- Bitmap names are `bm_<id>_state_0.png`. One `<id>` per bone. `<edgeAsset state="0">` matches. No boil frames.
- Empty bitmap, no colour, and no regions are loud failures (`SystemExit`). Do not substitute a blank bone.
- A fill whose area is more than 85% of the padded canvas is a leak. Stop.
- Outline and fill of a dividing line must differ by well over 0.06 OKLab. The tracer already strokes a region in that region's own colour; do not add a same-colour ink line on top.
- Minimum feature is about 22 px at brush 14. A stroke that never travels 12 px raises `SystemExit`.
- Do not draw the pink bubble. Do not trace `common:sign`. Do not divide a bubble's scale (there is no bubble).
- Do not build iOS or Android. Do not commit unless asked. Do not write tests unless asked.
- Python is `tools/bonepaper_gen/.venv/bin/python` from `at_elements`. Plain `python3` has no Pillow.

|---|---|---|
| Head, hair, ears | One compact polygon. Spikes are the contour, not separate strokes. | Short side of the min-rect ≥ 42. |

| Ears | 26 px bumps on that same contour. | |
| Eyes | Two ellipses, 70×60, sentinel. | Inradius leaves ≥ 20 px of white inside the outline. |
| Pupils | 26 px circles, `#5A5A5A`, centered in the eyes. | Peak ≥ 70. |
| Mouth | One `#C44B3A` ellipse, 96×56. | |

| Nostril | Omit. | A dot must travel 12 px. At that size it would be a nose. |
| Torso | Rounded rect 72×120. | Short side 72 ≥ 42, so compact, not a limb stroke. |

- [ ] **Step 1:** Add `build.py` that imports `regions` and `brush_svg` from `out/bluehairsvg/build.py` the same way `out/lion/build.py` does (`importlib`, do not edit that file).

- [ ] **Step 2:** Paint each source with Pillow. Integer pixels, no antialiased fringe (the tracer treats a dark fringe as ink). Draw later shapes over earlier ones: head blue, eyes, pupils, mouth, tooth band.

- [ ] **Step 3:** Before tracing, classify each bitmap and `SystemExit` with the name if the test in the brush table fails. Print `short`, `long`, and `elongated` for the trident and the torso. Elongated means `short < 42 and long > short * 2.2`.

```python
def assert_kind(name, geom, kind):
    rect = geom.minimum_rotated_rectangle
    corners = list(rect.exterior.coords)[:4]
    edges = [math.dist(corners[i], corners[(i + 1) % 4]) for i in range(4)]
    short, long = min(edges), max(edges)
    elongated = short < 42 and long > short * 2.2
    print(f"{name} short={short:.1f} long={long:.1f} elongated={elongated}")
    if kind == "limb" and not elongated:
        raise SystemExit(f"{name} is not a limb")
    if kind == "compact" and elongated:
        raise SystemExit(f"{name} would be drawn as one stroke")
```
